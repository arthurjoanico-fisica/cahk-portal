PARA PUBLICAR:
1. Extraia o arquivo ZIP.
2. Abra o repositório GitHub cahk-portal.
3. Entre na raiz do repositório.
4. Envie/substitua OS ARQUIVOS E PASTAS QUE ESTÃO DENTRO DO ZIP.
   Não envie a pasta cahk_v60work como uma pasta adicional.
5. Faça o commit na branch main.
6. Aguarde o deploy automático do Cloudflare Worker.
7. Abra https://cahk.app/build.txt
8. Confirme: CAHK Portal build 6.0-sistema-completo
9. Faça Ctrl + F5 ou abra uma aba anônima caso o navegador mantenha cache antigo.
